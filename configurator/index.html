lonewrt profile configurator

For lonewrt release . Start your run on GitHub with this version.

Everything stays in this page. It sends nothing, loads nothing from outside and keeps nothing in the browser: no cookies, no browser storage, so a reload empties the form. The form holds secrets (Wi-Fi password, tokens, keys), so close the tab when you are done.

Start from an existing profile (optional)

Paste the text of a profile or open a saved .conf file. Its values go into the form, a key it lacks gets the default of this release and is marked new, and a key this release no longer has is named as left out. Only KEY='value' lines are read; nothing is run.

How to get the Telegram bot token and the chat ID

You do these steps yourself in Telegram and in your own browser. This page never contacts Telegram.

  1. In Telegram open a chat with @BotFather (the real one has a blue tick). Send /newbot, then give the bot a name and a user name that ends in bot. BotFather replies with a token that looks like 123456789:AAH.... Put it into TG_BOT_TOKEN. Whoever has the token controls the bot, so keep it secret.
  2. Open a chat with your new bot (BotFather's reply links to it) and send it any message, for example /start. For a group instead: add the bot to the group and send a command there, for example /start@your_bot_name.
  3. In your own browser open the address https://api.telegram.org/bot<TOKEN>/getUpdates with your token in place of <TOKEN>. The reply is text that holds "chat":{"id":123456789. That number is the chat ID for TG_CHAT_ID; a group's ID is negative, for example -1001234567890. When result is empty, send the bot another message and reload.

The address contains your token: do not share it or open it on a computer that is not yours. The bot answers only in the chat whose ID you give, and anyone in that chat can read the Wi-Fi password and restart the router.

Your profile

One KEY='value' line per key, in the order of generic.conf. Copy it into the GitHub secret LW_PROFILE, or save it as <name>.conf and keep that file: it holds your passwords, and this page of a later release loads it.
